# StudentHub Portal

StudentHub Portal is a student-facing web project that brings common academic information and actions into one place. It is built as a multi-page static website using HTML, CSS, and JavaScript.

## Features

- Home and About pages
- Student registration and login pages
- Student dashboard and profile
- Events & workshops page
- Attendance information
- Assignment details
- Course information
- Academic results
- Contact and feedback pages

## Run locally

1. Clone or download this repository.
2. Open `index.html` in a web browser.
3. Use the navigation links to visit the portal pages.

No build step or package installation is required.
